# Callback

Interview-preparation prototype for STEM students: turn real work into evidence you can explain, alone, in the interview.

- [`callback/`](callback/) — the app (React + TypeScript, Vite) and its local AI backend. See [callback/README.md](callback/README.md) for setup.
- [`assignment/`](assignment/) — Lesson 7 mid-term deck (`Callback_Lesson7_Midterm.pptx` / `.pdf`), plus the scripts that capture prototype screenshots and build the deck.

Mei Lin and Bayline Freight are fictional. Callback does not predict hiring.
